Every row is scored by the same function. Nothing is hard-coded per name or per category: the category multiples are calibrated from the snapshot's own live-token protocols.

  1. Category multiple — the category's median market-cap / TVL across the snapshot's live-token protocols (clamped 0.05–1.2). A category with fewer than 3 live samples falls back to the global median.
  2. Base — TVL × category multiple.
  3. Growth — 7-day change clamped to −50…+150%, weighted 0.6.
  4. Maturity — 0.6 + (age ÷ 730 days, capped) × 0.4. Unknown age counts as 365 days.
  5. Chains — +2% per chain, up to 5 chains (+10% max).
  6. Implied value — base × growth × maturity × chains, capped at $100T.
